# agents/

This toolkit has no tracked specialist agents. Plan 009 retired them into skill
references (`skills/*/references/`); routing picks a skill, and a dispatched
worker is the built-in `general-purpose` agent with that skill loaded.

- `INDEX.json` here is generated by `scripts/generate-agent-index.py` and is
  gitignored.
- Private overlay agents live in the private tree and merge in at install time.
- Do not delete this file. The private-name leak gate and the ADR creation gate
  find the toolkit repo by `agents/` and `skills/`; without it they switch off
  in fresh clones. `scripts/tests/test_agents_dir_marker.py` guards it.
