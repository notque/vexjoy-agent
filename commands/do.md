# /do - Smart Router

Route user requests to the right skill and execution worker.

## Instructions

Call the Skill tool with `do`. Follow its classification, routing, enhancement, and execution phases.

```
Base directory: $CLAUDE_PROJECT_DIR or the current working directory
Skill file: skills/meta/do/SKILL.md
```

**Phase 1: CLASSIFY** — Assess complexity, check parallel patterns
**Phase 2: ROUTE** — Select skill (and worker when dispatching), display routing banner
**Phase 3: ENHANCE** — Stack verification, review, and parallel subagent enhancements
**Phase 4: EXECUTE** — Create the plan and execute on the main thread or dispatch through `build-dispatch.py`. The builder emits `Call the Skill tool with \`skill-name\`.` once for the primary skill and each callable stack skill.

Learning capture runs automatically via hooks — no router step (see "Learning Capture" in the skill).

The routing banner MUST be the first visible output:
```
===================================================================
 ROUTING: [brief summary]
===================================================================

 Selected:
   -> Worker: [main|general-purpose|<overlay-agent>]
   -> Skill: [name]

 Invoking...
===================================================================
```

For complete routing, force-route triggers, and dispatch rules, read `skills/meta/do/SKILL.md`; the routing manifest is generated by `scripts/routing-manifest.py` from the INDEX files (single source of truth).

ARGUMENTS: $ARGUMENTS
