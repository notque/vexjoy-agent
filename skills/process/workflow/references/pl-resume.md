# Resume contract

Discover state in this order: repository handoff artifact, saved plan/objective
state, git status/diff/log, then conversation. Validate timestamps, branch/base,
referenced paths, and uncommitted files against current reality. Present the
reconstructed outcome, completed evidence, drift, blockers, and next action
before editing. A stale or conflicting handoff is evidence to reconcile, not an
instruction to overwrite newer work. Remove one-shot artifacts only after the
resumed state has been safely incorporated.
