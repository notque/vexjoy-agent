# Architecture decision record schema

```markdown
# ADR-<number>: <decision>
Status: proposed | accepted | superseded | rejected
Date: <YYYY-MM-DD>
Deciders: <owners>

## Context
<forces, constraints, incident or evidence>
## Decision
<chosen rule and exact scope>
## Alternatives
- <option>: <why rejected>
## Consequences
- positive:
- negative/trade-off:
## Validation
<command, observation, or metric that can falsify the decision>
## Revisit when
<boundary or signal>
```

An ADR records a consequential choice, not a session summary. Incident-derived
rules cite the incident/evidence and state where the rule does not apply.
