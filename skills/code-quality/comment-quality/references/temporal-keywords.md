# Temporal comment candidates

Match these phrases case-insensitively in comments, then inspect context:

`now`, `new`, `old`, `previously`, `formerly`, `originally`, `recently`,
`latest`, `legacy`, `added`, `removed`, `updated`, `changed`, `fixed`,
`improved`, `enhanced`, `refactored`, `optimized`, `replaced`, `migrated`,
`upgraded`, `used to`, `as of`, `since version`, `better than before`,
`faster than before`, `temporary`, `interim`, and `stopgap`.

Preserve contractual uses: copyright notices, `@generated`, `@deprecated`,
framework/API `Since` or `Version` tags, and runtime ordering or state.
