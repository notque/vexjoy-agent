# Dissolving a skill into a Jev program

Inventory each phase and classify it as deterministic, judgment, or generation. Move parsing, retrieval, arithmetic, thresholds, side effects, and stopping into code. Turn only bounded judgments over supplied evidence into Jev heads. Leave genuine drafting/synthesis to an LLM.

For every head, name the unit, evidence, primitive, answers, policy action, unavailable path, and labeled comparison. Walk the 11 positions in `composition-positions.md`; most should be empty. Preserve the old skill/EVAL as the behavioral baseline until a group-disjoint heldout shows agreement and downstream action quality.

The repository's `joy-check` decomposition is the canonical example: code finds claims and owns thresholds; Nouls assess grievance, person-focus, unsupported motive, earned hope, and constructiveness; policy combines named probabilities; only prose repair remains generative. Never let the judge rewrite the artifact or infer provenance absent from state.

A skill is dissolved only when the runtime no longer needs its prose procedure, failures are explicit `unknown`, receipts are persisted, and the replacement beats deterministic baselines on heldout data.
