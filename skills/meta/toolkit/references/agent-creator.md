# Agent creation contract

Before adding an agent, search the live agent index for overlapping domain
ownership. Extend an existing agent when its authority boundary already fits.

Agent identity must match its filename. Select tools by role and least required
authority; validate every trigger, companion skill, and referenced file against
the live indexes. Provide specific domain ownership and exclusion boundaries,
not a generic persona. Add positive, negative, and near-miss activation cases.

After changes, regenerate the agent index and routing map and run repository
reference validation. A structurally valid agent is not proven useful until its
activation and output cases pass.
