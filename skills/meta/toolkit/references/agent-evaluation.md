# Agent evaluation contract

Separate deterministic integrity from behavioral quality.

Deterministic checks cover frontmatter parsing, filename identity, allowed
tools, live companion names, reference existence, and script syntax. Behavioral
checks use realistic activation and output cases with cited artifacts. Never
turn a structural point total into proof of domain correctness.

Reports identify the exact file/check, observed evidence, impact, and smallest
corrective action. Batch summaries retain per-agent failures rather than hiding
them in an average.
